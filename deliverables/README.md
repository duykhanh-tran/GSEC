# Gói bàn giao cuối

- `Propotype-React-Final-2026-09-06.zip`: source, build, test, scripts, báo cáo và tài liệu.
- `final-manifest.json`: SHA-256 và dung lượng từng file trong phạm vi gói.
- `checksums.sha256`: SHA-256 của ZIP cuối.
- `validation.log`: trạng thái các cổng bàn giao.

Không giải nén đè lên `Propotype/` hoặc các thư mục WS. Hệ HTML là baseline/rollback độc lập.
